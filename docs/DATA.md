# Данные и их происхождение

Исследование использует один срез от 13 марта 2026 года. Данные собраны автором из открытых каталогов; код сбора в этот репозиторий не входит.

| Магазин | Источник | Позиций |
|---|---|---:|
| Sklavenitis Ypsonas, Limassol | [Каталог Wolt](https://wolt.com/el/cyp/limassol/venue/sklavenitis-ypsonas) | 3 342 |
| AlphaMega, Limassol | [Онлайн-каталог AlphaMega](https://www.alphamega.com.cy/en/groceries) | 8 672 |

Поля `scraped_at` относятся к вечеру 13 марта 2026 года, UTC. Не утверждается, что это цены физических магазинов или что цены не менялись после сбора.

## Включённые файлы

| Файл | Назначение |
|---|---|
| `data/processed/sklavenitis_products.csv` | Финальный обработанный каталог Sklavenitis; порядок строк задаёт `sk_0`, `sk_1`, … |
| `data/processed/alphamega_products.csv` | Аналогичный каталог AlphaMega; порядок строк задаёт `am_0`, `am_1`, … |
| `data/processed/matched_pairs.csv` | 841 выбранная пара, цены, категории, извлечённые размеры и происхождение меток |
| `data/reference/ml_labeled_pairs.csv` | 882 пары: 436 match и 446 non-match; семь числовых признаков |
| `data/reference/label_df_random42_labeled_500_reviewed_v5_canonical.csv` | 500 строк ручной декомпозиции названий для словарей |
| `data/reference/*vocab.csv` | Словари брендов и типов товаров |
| `data/reference/*dictionary_current.csv` | Итоговые экспортированные ручные правила |
| `data/reference/sklavenitis_reviewed_overrides.csv` | 132 строки финальных исторических решений, которые не полностью восстанавливаются по словарю |
| `data/reference/historical_ml_cv.csv` | Исторические результаты 3 моделей × 18 порогов |

Исходные XLSX с цветовой разметкой не нужны для основного запуска: решения экспортированы в CSV. Точные оригиналы сохранены локально; перечень и контрольные суммы — `docs/archive_manifest.csv`.

## Основные поля

- `product_name`: исходное название карточки; `product_core`: очищенная текстовая основа.
- `size_total_base`, `size_base_unit`: извлечённая суммарная фасовка в г/мл/шт. Пропуск не равен нулю.
- `brand_pred_with_manual`, `product_type_pred_with_manual`: итоговые словарные значения с учётом ручных правил.
- `grade`: дополнительные размерные/модельные характеристики.
- `price`, `promo_price`: исходные обычная и акционная цены. В итоговых парах поля `*_price_eur`, `*_promo_price_eur` содержат числовые цены в евро.
- `*_effective_price_eur`: используемая цена — заполненная положительная акционная, иначе обычная.
- `size_key_sk`, `size_key_am`: ключи вида `500_g`. `same_size_key=True` также бывает при двух пустых строках; отдельная проверка требует заполненности.
- `manual_match`: метка принятого совпадения. В финальном файле все значения 1, но происхождение решения может быть автоматическим или ручным.
- `combined_label_sources`: историческое происхождение принятой метки. Итоговые решения и разрешение дубликатов не подменяются новым прогнозом модели.
- `item_id_sk`, `item_id_am`: технические идентификаторы строк, не идентификаторы покупателей.

Оценки TF-IDF в ML-таблице рассчитаны по полному пулу кандидатов. Это фиксированные текстовые признаки, а не обучение TF-IDF внутри каждого CV-fold; эксперимент проверяет классификацию на этих готовых признаках.

## Ручные решения при повторении подготовки

Во время аудита повторение словарного этапа дало расхождения с финальным снимком Sklavenitis: 131 бренд, 71 остаток названия после вычитания бренда и одно исходное название. Объединение затронутых строк — 132.

Для прозрачного повторения эти итоговые значения экспортированы из исторического снимка в `sklavenitis_reviewed_overrides.csv`. Это **не новая разметка и не автоматически найденные правила**. Скрипт применяет их только к той же строке с тем же `product_core`; для новой выгрузки переносить их без проверки нельзя. После применения проверяемые поля совпадают с сохранёнными снимками.

## Публикация данных

Файлы содержат сведения о товарах и ценах, а не данные покупателей. Из публичных рабочих таблиц исключены служебные локальные пути и данные Excel-разметки, не нужные для повторения расчётов. Изображения товаров не скачиваются и не включаются в проект; в каталогах остаются исходные ссылки.

Публичная доступность источника сама по себе не является лицензией на повторное использование базы. Отдельное разрешение/лицензия источников в материалах проекта не зафиксированы; репозиторий не заявляет права на сторонние названия, изображения или каталоги. Полные raw-выгрузки не включены, обработанные данные сохранены для проверки исследования. Автоматическая загрузка сайтов при запуске не выполняется.
