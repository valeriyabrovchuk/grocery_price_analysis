# Аудит подготовки к публичному просмотру

Дата подготовки: **2 ноября 2026 года**. На этапе аудита коммиты и push не выполнялись. Видимость репозитория и история Git не изменялись.

## Исходное состояние

Основной файл — `groceries_comparison_limassol.ipynb`, включавший подготовку, словари, matching, ML и статистику. В корне также находились временный notebook, две резервные копии и несколько Excel-версий. В `output/` лежали большие воспроизводимые таблицы, версии ручной разметки и распакованные Office-файлы. Одноразовые скрипты смешивались с основным кодом; в Git были `__pycache__`, временные файлы и Excel lock-файл.

До начала работы обнаружены незакоммиченные изменения основного ноутбука и уже удалённый lock-файл Excel. Рабочая версия ноутбука сохранена побайтно; существующее удаление lock-файла не отменялось.

## Безопасное сохранение

255 оригинальных файлов, около 317 МБ, перенесены внутри рабочего каталога в `.local_archive/original_worktree/`. Ничего не удалялось безвозвратно. Манифест с исходными относительными путями и SHA-256 — `archive_manifest.csv`.

Публичные архивные копии двух notebook и старых скриптов сохранены в `archive/`: очищены outputs и локальные пути. Точные байты исходников находятся в локальном архиве, который исключён из Git. Старые рабочие XLSX и промежуточные расчёты остаются там же. Повторный публичный запуск не зависит от этого архива.

- Четыре последовательных notebook и переносимые скрипты по этапам.
- Обработанные каталоги, ручные словари и метки как фиксированные входные данные.
- Небольшой итоговый файл на 841 пару вместо таблицы с 100+ техническими колонками.
- Пересчитываемые графики, таблицы и метрики.
- Зафиксированное окружение, проверки данных, инструкции запуска и ограничения.

Одноразовые изменения Excel и старые версии словарей не используются в актуальном запуске. Убран начальный повторный импорт данных из середины рабочего notebook; вместо зависимостей от скрытого состояния каждый notebook загружает собственные входы.

Поиск выполнялся по шаблонам приватных ключей, токенов GitHub, AWS access key, сервисных токенов и присваиваний credentials. Дополнительно проверялись локальные пользовательские пути, адреса электронной почты и текст/XML внутри Office ZIP. Потенциальных ключей/токенов по этим шаблонам **не найдено**.

После исключения одного ложного срабатывания на собственный шаблон сканера найдено **157 мест** с локальными пользовательскими путями в рабочем дереве и истории: notebook outputs, код и метаданные Excel. Это число мест, а не число уникальных людей. История также содержит **две Git author identity**. Старые Excel и compiled-файлы исключены из текущей публичной версии; пути в публичном коде и notebook очищены.

Проверка по шаблонам не гарантирует отсутствие любого секрета. Семь бинарных/compiled объектов не анализировались как текст. Сбор персональных имён по произвольному тексту не является исчерпывающим; технические Git-идентичности авторов отдельно не обезличивались. Полный отчёт с местоположениями сохранён локально в `.local_archive/audit/`, значения потенциальных credentials в отчёт не выводятся.

## Публикация и история Git

**Текущее дерево очищено; исходная история Git не очищена.** Простая смена видимости этого существующего репозитория сделает доступными также старые файлы и локальные пути в коммитах. Новая `.gitignore` не удаляет уже сохранённое из истории.

Подготовлен безопасный способ переноса текущего проекта без старой истории:

```bash
python scripts/validate_project.py
python scripts/make_public_export.py
```

Получится `.local_archive/grocery_price_analysis_public.zip`: исходники, данные для анализа, документация и результаты, без `.git`, исходных raw, окружений, временных файлов и точных локальных резервных копий. Скрипт дополнительно сканирует включаемое содержимое на шаблоны credentials и локальные пути; при находке экспорт останавливается.

Этот архив можно использовать как содержимое нового публичного репозитория, сохранив первоначальный приватный проект и всю его историю. Первый коммит и публикацию выполняет автор. Если нужна публикация именно существующего репозитория с его историей, требуется отдельное решение о её очистке; оно здесь не выполнялось.
